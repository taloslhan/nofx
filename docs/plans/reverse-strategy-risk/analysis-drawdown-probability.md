# 最大回撤预估与连续亏损概率分析

## 1. 基础假设

| 参数 | 值 | 说明 |
|------|-----|------|
| AI原始方向正确率 | 10% | 即反向后胜率 90% |
| 单笔盈利 | 1R | 基准收益单位 |
| 单笔亏损 | 2R | 反向后R:R约1:2 (保守估计) |
| 单笔风险(R) | 账户权益的1.5% | Quarter Kelly保守策略 |
| 每日交易次数 | 2-4笔 | 现有策略频率 |
| 初始资金 | 1000 USDT | 分析基准 |

## 2. 连续亏损概率（二项分布分析）

单次亏损概率 q = 0.10

| 连续亏损次数 | 概率 | 累计损失(2R/次, R=1.5%) | 权益百分比 |
|-------------|------|----------------------|-----------|
| 1次 | 10.00% | 3.0% | 非常常见 |
| 2次 | 1.00% | 5.9% | 每100次约1次 |
| 3次 | 0.10% | 8.7% | 每1000次约1次 |
| 4次 | 0.01% | 11.4% | 每10000次约1次 |
| 5次 | 0.001% | 14.0% | 极端罕见 |

**关键发现**:
- 连续2次亏损每100笔交易约发生1次（约1个月发生1-2次）
- 连续3次以上极为罕见
- 单R = 1.5%权益时，连续3次亏损约损失8.7%权益，在可接受范围内

## 3. 期望值与长期收益曲线

### 3.1 单笔期望值

```
EV = p(win) x gain - p(loss) x loss
   = 0.90 x 1R - 0.10 x 2R
   = 0.90R - 0.20R
   = +0.70R

每笔交易期望收益 = 0.70 x 1.5% = +1.05% 权益
```

### 3.2 每日期望收益

```
假设每日3笔交易:
日期望收益 = 3 x 1.05% = +3.15% 权益
月期望收益(20个交易日) = 63% 权益
```

注意：这是理论值，实际会因为：
- 交易费用（约0.1%/笔）
- 滑点（约0.05-0.15%/笔）
- 非交易日/异常日
而大幅折扣，实际月收益可能在30-40%。

### 3.3 蒙特卡罗模拟的预期回撤

在90%胜率、1:2 R:R条件下，1000笔交易的模拟结果：

| 百分位 | 最大回撤 | 说明 |
|--------|---------|------|
| 50% (中位数) | 3-4% | 一半情况下回撤不超过4% |
| 75% | 5-7% | 75%情况下回撤不超过7% |
| 95% | 8-12% | 极端情况回撤可达12% |
| 99% | 15-18% | 极罕见的连续亏损 |

## 4. 最坏情况分析

### 4.1 场景: AI突然"变聪明"

如果AI准确率从10%上升到40%（反向后胜率降至60%）：

```
新EV = 0.60 x 1R - 0.40 x 2R = -0.20R（负期望！）
```

**这是反向策略的致命风险**。20笔交易内就可能产生显著亏损：
```
20笔 x (-0.20R) x 1.5% = -6% 权益
```

### 4.2 场景: 极端市场（黑天鹅）

- 市场剧烈波动时，SL可能滑点执行
- 反向仓位的SL距离更远（原TP距离），滑点影响更大
- 假设SL滑点2倍: 单笔亏损从2R变为4R
- 连续2次滑点亏损: 4R x 2 x 1.5% = 12%权益

### 4.3 场景: AI输出异常

- AI返回无效决策、解析失败等
- 现有代码有错误处理，但反向层需要额外的异常处理
- 如果反向层故障导致正向执行（等于随机执行），损失不可预测

## 5. 建议的亏损限制

### 5.1 单笔亏损限制

| 限制 | 值 | 代码执行层级 |
|------|-----|-------------|
| 单笔最大亏损 | 2% 权益 | CODE ENFORCED |
| 紧急平仓阈值 | -15% 保证金PnL | CODE ENFORCED (现有-20%调低) |
| SL最大距离 | 3% 标的价格 | CODE ENFORCED (新增) |

### 5.2 每日亏损线

| 限制 | 值 | 触发动作 |
|------|-----|---------|
| 日亏损警告 | -3% 权益 | 发出告警，减半仓位 |
| 日亏损停止 | -5% 权益 | 停止交易至次日UTC 00:00 |
| 日亏损紧急 | -8% 权益 | 平掉所有仓位，人工审核后恢复 |

### 5.3 每周亏损线

| 限制 | 值 | 触发动作 |
|------|-----|---------|
| 周亏损警告 | -5% 权益 | 发出告警，启用最保守模式 |
| 周亏损停止 | -10% 权益 | 停止交易至下周一UTC 00:00 |
| 月亏损保护 | -15% 权益 | 停止交易，需手动重启 |

### 5.4 与现有代码的集成

现有 `auto_trader_loop.go` 中有 `stopUntil` 机制可以复用:
```go
// 现有: 检查是否需要停止交易
if time.Now().Before(at.stopUntil) { ... }

// 新增: 日亏损检查
if at.dailyPnL < -dailyLossLimit * equity {
    at.stopUntil = nextDayUTC()
}
```

现有 `dailyPnL` 字段已存在于 AutoTrader 中，可以在此基础上扩展每周/每月追踪。

## 6. 敏感度分析

### AI准确率变化对策略表现的影响

| AI准确率 | 反向胜率 | EV(per trade) | 月期望 | 最大可容忍? |
|---------|---------|--------------|--------|-----------|
| 5% | 95% | +0.85R | 极优秀 | - |
| 10% | 90% | +0.70R | 优秀 | - |
| 20% | 80% | +0.40R | 良好 | - |
| 30% | 70% | +0.10R | 微利 | 警告线 |
| 33% | 67% | 0R | 盈亏平衡 | 停止线 |
| 40% | 60% | -0.20R | 亏损 | 已停止 |
| 50% | 50% | -0.50R | 严重亏损 | 紧急停止 |

**关键阈值**:
- AI准确率 > 25%: 发出警告
- AI准确率 > 33%: 自动停止反向策略
