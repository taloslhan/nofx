**角色**: 风控专家 (Risk Management Expert)

## 概述

本报告从风控专家视角，对"AI反向开仓"策略进行系统性风险评估。核心前提是AI策略方向错误率约90%，通过反向开仓将其转化为约90%的胜率优势。

分析基于现有nofx代码库的4层风控体系（代码强制 > 市场检查 > 监控日志 > AI指导），聚焦反向操作引入的新风险维度。

## 核心发现摘要

**1. 最关键风险**: R:R比率反转问题
- AI原始R:R为3:1（TP距离 = 3x SL距离），反向后变为1:3
- 现有 `MinRiskRewardRatio: 3.0` 的代码强制检查将拒绝所有反向交易
- 必须为反向策略设计独立的R:R验证逻辑

**2. 核心优势**: 90%胜率下的期望收益为正
- 假设反向后R:R为1:2，胜率90%: EV = 0.9 x 1 - 0.1 x 2 = +0.7R（正期望）
- 即使R:R劣势，高胜率仍能创造正期望值

**3. 最大威胁**: AI"变聪明"（准确率提升）
- 如果AI准确率从10%上升到50%，反向策略胜率降至50%，在1:2的R:R下EV变为负值
- 必须建立滑动窗口监控和自动停止机制

**4. 风控参数调整方向**: 更保守的仓位 + 更宽松的R:R + 更严格的监控
